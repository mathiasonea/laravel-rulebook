# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues or discussions.

Email security reports to [office@mathiasonea.at](mailto:office@mathiasonea.at) with:

- A description of the vulnerability and its impact
- Steps or a minimal example that reproduces it
- The affected package version or commit
- Any suggested mitigation, if known

You can expect an acknowledgement within five business days. Please allow time to investigate and release a fix before publicly disclosing the issue.

## Supported versions

Until the first stable release, security fixes are made on the latest development version. After stable releases begin, supported versions will be documented here.
